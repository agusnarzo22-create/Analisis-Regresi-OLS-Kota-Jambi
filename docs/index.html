Kesimpulan

  • H1 didukung — belanja modal pendidikan berpengaruh positif dan signifikan terhadap IPM (p = 0,0364). Setiap kenaikan satu satuan indeks belanja modal pendidikan meningkatkan IPM Kota Jambi sebesar 0,0521 poin.
  • H2 tidak didukung — belanja modal kesehatan berpengaruh negatif dan signifikan (p = 0,0153). Setiap kenaikan satu satuan indeks belanja modal kesehatan menurunkan IPM sebesar 0,0660 poin. Hal ini tidak berarti belanja kesehatan merugikan IPM, melainkan dapat mencerminkan alokasi berbasis kebutuhan serta efek jangka panjang belanja modal.
  • Daya penjelas model cukup kuat (R² = 0,583, Adj. R² = 0,479), jauh di atas model gabungan 97 kota (R² = 0,006). Secara simultan kedua variabel berpengaruh signifikan (F = 5,602; p = 0,0301).
Keterbatasan: jumlah observasi terbatas (11 tahun), model belum mengontrol variabel lain (PAD, transfer pusat, kemiskinan, pengangguran), dan terdapat indikasi autokorelasi pada residual (Durbin-Watson = 0,705).
