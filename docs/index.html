Kesimpulan

  • Belanja modal pendidikan tidak berpengaruh signifikan terhadap IPM (p = 0,3886). Perubahan alokasi belanja modal pendidikan tidak terbukti meningkatkan capaian IPM pada periode yang sama.
  • Belanja modal kesehatan berpengaruh signifikan namun negatif (p = 0,0142). Hal ini tidak berarti belanja kesehatan merugikan IPM, melainkan mencerminkan pola alokasi berbasis kebutuhan (kota dengan IPM rendah menganggarkan belanja modal kesehatan lebih besar) serta sifat belanja modal sebagai investasi jangka panjang yang dampaknya baru terasa beberapa tahun kemudian.
  • Daya penjelas model rendah (R² = 0,0062). IPM lebih banyak ditentukan faktor lain di luar belanja modal layanan dasar, seperti belanja operasional, kualitas SDM, dan kondisi sosial-ekonomi daerah.
Catatan: secara simultan kedua variabel berpengaruh signifikan (F = 3,331, p = 0,0361), namun kontribusinya terhadap variasi IPM sangat kecil.
